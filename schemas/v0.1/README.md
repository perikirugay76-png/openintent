# OpenIntent v0.1 Schemas

These schemas use JSON Schema draft 2020-12.

Shared definitions live in `defs.schema.json`. They are for reusable semantic structures such as `actor`, `constraint`, and `preference`, not for collapsing distinct protocol objects.

Schema `$id` values should remain stable for the v0.1 line. Relative `$ref` values should resolve within this directory.
